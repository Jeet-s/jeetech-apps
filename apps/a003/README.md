# BlockDay - Time Blocking

Fast time blocking with a simple time block planner. Offline, no account.

- Google Play: https://play.google.com/store/apps/details?id=com.jeetech.a003
- Privacy policy: https://jeet-s.github.io/jeetech-apps/a003/privacy.html
- Current version: 1.0.0

`app/` is the Expo (React Native) source as shipped; `store/` holds the listing and graphics.
